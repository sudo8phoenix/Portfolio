03 / ENGINEERING

The decisions behind it.

Separate UI, orchestration and services

React and Vite provide the dashboard. FastAPI exposes APIs and WebSockets, with modular services, repositories and tool integrations behind the conversational flow.

Give state a durable home

PostgreSQL stores persistent records; Redis supports cache and runtime state. This keeps the interface from being the only place where a workflow exists.

Include operational components

Docker Compose connects the services. Prometheus and Grafana configuration provides a foundation for monitoring, distinct from a verified production service-level objective.

04 / EVIDENCE & LIMITS

Claims with context.

2Named Google integrations: Gmail and Calendar
API + WebSocketDocumented interaction channels

The public documentation describes task and conversation workflows, OAuth integrations, persistence, container deployment and monitoring. These are documented capabilities; the reviewed overview does not establish a successful-task rate or production uptime.

Current limits & next validation

Connected workflows depend on provider credentials and integration configuration. A useful next check is a fixed task suite with explicit expected actions, failures, permissions and recovery behavior. No real email or calendar action occurs in this portfolio example.
