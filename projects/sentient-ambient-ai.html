From a camera signal to ambient light.

01 / THE PROBLEM

What needed solving.

Frame-by-frame classifier outputs can flicker. A physical lighting system needs a more stable signal and a clear boundary between the computer performing inference and the microcontroller driving LEDs.

03 / ENGINEERING

The decisions behind it.

Smooth before acting

A default 50-frame buffer and strict-majority rule stabilize predictions. Cooldown and no-face handling reduce abrupt changes and define behavior when observations disappear.

Split inference from actuation

Python handles camera input and DeepFace. The ESP32 receives a compact command over Serial or optional HTTP and smoothly blends a WS2812B strip using NeoPixel.

Keep audio on the host

Music plays on the laptop, locally or through optional Spotify integration. An optional per-user classifier can be trained on DeepFace embeddings.

04 / EVIDENCE & LIMITS

Claims with context.

50 framesDefault stabilization window
7 labelsConfigured expression categories

The README establishes hardware wiring, command paths, configurable smoothing and optional training. The numbers describe configuration; they do not measure emotion-recognition accuracy or a wellbeing outcome.

Current limits & next validation

Facial expressions do not reliably establish someone’s internal emotional state. This is an experimental interaction, not a psychological assessment. Robust evaluation would include false switches, lighting changes, no-face behavior and user control.
