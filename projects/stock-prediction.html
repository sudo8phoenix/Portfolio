03 / ENGINEERING

The decisions behind it.

Keep tuning separate from testing

The README describes training, validation and test splits. Keras Tuner selects network width, depth and learning rate using validation behavior.

Use a compact modelling pipeline

MinMaxScaler prepares inputs. Dense ReLU layers, a linear output and Adam optimize mean squared error, with early stopping.

Inspect the comparison

Predicted-versus-actual visualizations help diagnose behavior. A stronger next evaluation would explicitly verify chronological splits, scaling scope and a naive forecasting baseline.

04 / EVIDENCE & LIMITS

Claims with context.

TensorFlowDense neural-network experiment
Keras TunerArchitecture and learning-rate search

The README documents the dataset, modelling setup and a predicted-versus-actual plot. It does not establish a reproducible held-out error or a comparison to a persistence baseline, so no accuracy or return claim is made.

Current limits & next validation

The notebook is a learning experiment, not a trading tool. Time ordering, leakage checks and a naive baseline are necessary before interpreting forecasting quality. The portfolio example contains no live financial data or investment recommendation.
